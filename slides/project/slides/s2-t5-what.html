What are LangChain, LangGraph and LangFuse?

Three open-source projects that appear constantly in agent work. The platform-agnostic sessions use these only — no licensed frameworks are required.

LangChain

A library of components: model wrappers, retrievers, tool abstractions, output parsers. Useful when you want the standard interface rather than the standard opinions.

Buys you: adapters you did not write.
Costs you: a layer between you and the API.

LangGraph

A graph runtime for agents: nodes, edges, shared state, checkpoints. This is where multi-agent flows get real structure.

Buys you: the loop, the state and the handoffs.
Costs you: the loop is now someone else's.

LangFuse

Open-source tracing and evaluation for LLM applications — the same job MLflow Tracing does inside Databricks.

Buys you: portable observability.
Costs you: another system to run.

Why we built the loop by hand first

Every one of these is a wrapper around the five steps from Session 1. Build it once and the frameworks become legible tools rather than magic.

Databricks equivalents

LangGraph is used directly in Session 7 via the Databricks LangChain integration. LangFuse's job is done by MLflow Tracing. There is no need to choose sides.
