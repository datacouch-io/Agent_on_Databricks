04

Databricks Genie

Goal: curate a Genie Agent, measure it with benchmarks, then call it from an agent.

2 hours  |  Labs 4A, 4B

Genie is the one component in this course you configure rather than code. That makes it the best place to ask a question the rest of the course keeps returning to: when you put a rule somewhere, who inherits it? Session 4 answers that empirically. We write an instruction in a Genie Agent, then call that Genie Agent from an agent that knows nothing about the instruction, and see whether it still applies. Timing: 1 minute.
