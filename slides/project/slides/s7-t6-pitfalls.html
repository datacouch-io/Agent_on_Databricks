Four of these were broken measuring instruments, and every one of them failed in the same direction — misjudging correct work. That is the habit worth taking home: open the failure, read the rationale, and decide each time whether you or the instrument was wrong.

Close the taught content with the mistakes, all of which are real and most of which are ours. Go down the list quickly — the room has met every one of these in context, so this is recall rather than teaching. The value is seeing them together, because the pattern is only visible in aggregate. The callout is the pattern. Four of the eight are broken measuring instruments: the correctness judge, the rationale extractor, the Genie inheritance check and the canary analysis. Every one of them failed in the same direction — marking correct work wrong. That direction is what makes the habit worth having, because the default experience of a failing metric is a week spent fixing an agent that was already right. Be honest about which were ours rather than the platform's. The inheritance check, the canary write-up and the n=3 reading were all our analysis, not a product defect. Saying so is the point: this is not a warning about vendors, it is a warning about measurement. If the room is engaged, ask which of these they expect to hit first. The answer is almost always the first one — building an agent for something that is a workflow — and that is a useful thing to have them say out loud before they go back to work. Timing: 4 minutes.
