What are AI Functions?

AI Functions let you call a model directly from SQL — ai_query, ai_classify, ai_extract, ai_summarize and more — so inference becomes part of a query rather than a service you call.

Called from SQL

In a SELECT, a view, or a pipeline. No client, no endpoint plumbing.

Batch by nature

Runs over a column of a table. Thousands of rows in one statement.

Governed

Unity Catalog permissions and Unity Gateway limits apply, as with any other query.

Not an agent

No loop, no tools, no state. One input, one output, per row.

Where it fits in this course

This is the workflow from Session 1, expressed in SQL. Classify four thousand invoices? That is ai_extract over a column — not an agent with a loop.

The analogy

A spreadsheet formula that happens to call a language model. Applied down a column, not reasoned about per cell.
