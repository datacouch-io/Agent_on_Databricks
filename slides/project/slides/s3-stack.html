Resist reading this list out. The single sentence at the bottom is the slide. Assembling this stack from separate vendors is entirely possible — a hosted model, a vector database, a tracing service, a feature store. What you lose is the shared boundary. Five products means five permission models, and the question "who was allowed to see the document this answer was built from?" becomes a research project. Here, the index inherits the table's grants. The trace lands in a catalog you control. The tool is a function someone either can or cannot execute. That is the argument for the platform, and it is worth more than any individual component in the list. Expected question: "Can I bring my own model?" Yes — external models register as serving endpoints and appear through the same interface. Everything in this course works the same way behind them. Timing: 3 minutes.
