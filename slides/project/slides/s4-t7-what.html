What is Genie Code?

Genie Code is the AI coding and data assistant for developers inside the Databricks workspace. It generates, optimises, explains and fixes code where you already work.

Where it works

Notebooks, the SQL editor, jobs, AI/BI dashboards and the file editor.

Built-in skills

Writing notebook code, exploring Unity Catalog, building dashboards, creating pipelines, working with MLflow.

Agent mode

For pipeline development: explores data, generates and runs code, and fixes its own errors from one prompt.

Extensible

Custom workspace or user skills in an .assistant/skills/ directory.

It shares the ontology

Genie One and Genie Code search the same knowledge base, so the metric definitions your data team curated also shape the code Genie Code writes.

Why it belongs in this course

It is an agent — a supervisor with skills, a loop, tools and a stopping condition. Everything from Session 1 applies to the thing writing your pipelines.
