ADDED TOPIC — not in the original outline, added because it bit us while building this course. On a trial workspace, agents.deploy() returns "Model serving is not available for trial workspaces", and the Agent Bricks page at /ml/bricks returns Page not found — even though the Agents entry is visible in the left navigation. A nav entry is not a feature. The link renders from static navigation, not from what your workspace has provisioned. Azure permits trial to premium only, never the reverse. So this is a decision to make before the cohort starts, not during Session 6. Analogy: this is the flight check, not the flight. Ten minutes now saves twenty people being blocked at the same moment later. Expected question: "Can I use Databricks Free Edition?" For Sessions 1 through 5, yes. The two Premium-only steps are deployment to Model Serving and the Agent Bricks walkthrough. Timing: 4 minutes.
