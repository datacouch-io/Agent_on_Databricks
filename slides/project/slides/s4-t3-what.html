What is a Genie benchmark?

A benchmark is a stored question paired with the ground-truth SQL — the query you would have written. Genie answers the question, runs both queries, and compares the result sets.

Question

Phrased as a user would ask it, not as a schema description.

Ground-truth SQL

Your correct query. The reference, written and reviewed by a person.

Both executed

Genie's query and yours. Rows compared, not query text.

A pass or a fail

Per case, with the generated SQL shown so you can see how it differed.

Why comparing rows is the key design choice

SQL has many correct spellings. A different join order, a HAVING instead of a subquery, a different alias — all correct. Comparing text would fail them all. Comparing results passes any query that returns the right answer.

The analogy

Marking a maths exam on the answer and the working, rather than on the handwriting.

This is the most quietly important feature in Session 4, and the design decision on the right is why. Spell out the problem it solves. You want a regression test for a component that is non-deterministic by construction. The same question can produce five different, equally correct queries on five different days. Any test that compares generated SQL to expected SQL fails constantly and teaches people to ignore it. Comparing result sets sidesteps that entirely. If the rows match the ground truth, the query was correct, however it was written. That gives you something genuinely rare here: a green-or-red signal you can trust and automate. The cost is honest and worth stating: someone has to write the ground-truth SQL, and write it correctly. That is real work, and it is the same work as writing a test fixture. Teams that resist it usually have no agreed definitions, which is itself the finding. Analogy: marking the answer, not the handwriting. Likely question: "What about questions with no single right answer?" Those do not belong in a benchmark. Keep benchmarks for questions with a defensible correct result, and use human review for the open-ended ones. Timing: 3 minutes.
