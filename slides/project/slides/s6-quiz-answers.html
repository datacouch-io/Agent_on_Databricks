Answers

1B, 2D, 3A, 4C  — and why the others fail.

1

B — The judge was wrong — Correctness requires ground truth and penalises correct refusals

The rationale read: “the response does not provide the refund the user requested”. The agent was right and the instrument was broken.

Three separate automated judgements during this course were wrong, and every one misjudged correct work. Open every zero and read the rationale; decide each time who was wrong.

2

D — RetrievalGroundedness

RetrievalGroundedness asks whether the answer is supported by what was retrieved — the hallucination detector. Use it early, because it needs nothing you have to write first.

Correctness and RetrievalSufficiency both require ground truth. RetrievalRelevance needs a RETRIEVER span to find — which is why span types are not cosmetic.

3

A — Set @previous to the current champion

Set it before you promote, not after. Rollback then becomes one metadata change — and if reverting is cheap you will do it early and argue about the cause afterwards.

Without aliases, rollback is a redeployment under incident pressure by someone who may not have deployed it. Teams hesitate — and hesitating during an incident is the actual cost.

4

C — Streaming the first token

Streaming changes perceived latency entirely while changing none of the underlying numbers. First token under about two seconds is the cheapest adoption lever you have.

Parallelising calls, lowering top-k and switching models all reduce real latency — parallelising is often the biggest genuine win — but the question asked which changes the experience without changing the measurement.
