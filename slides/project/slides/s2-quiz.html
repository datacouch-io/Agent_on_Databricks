Session 2 — Platform-Agnostic Agent Implementation

Knowledge check

Four questions. One correct answer each — answers on the next slide.

1

The retrieval seam is search_docs(query, k) returning {doc_id, text, score}. What must never cross it?

A  The score, because it is backend-specific

B  Vendor imports and vendor-specific parameters

C  The document text, which should be fetched separately

D  Anything larger than k results

2

Where is the cheapest place to improve an agent's tool selection?

A  Fine-tuning the model on your tool set

B  Adding deterministic routing rules before the model sees the request

C  Rewriting the tool description

D  Switching to a larger model

3

“Can I return the headphones I bought last month?” Why can a document retriever alone not answer this?

A  Vector search cannot match on the word “headphones”

B  Return questions always require human approval

C  The policy document is too long to retrieve in one chunk

D  It needs the policy and the customer's actual purchase — and it will guess the second

4

Why is authentication the hardest thing to port between runtimes?

A  Each runtime runs as a different principal, and the failure appears far from its cause

B  Tokens expire at different rates on each platform

C  Serving endpoints do not support authentication

D  The OpenAI client cannot hold more than one credential

Answer key: 1B, 2C, 3D, 4A. Run this as a poll, not a lecture. Read each stem aloud, take a show of hands on every option, and only then move to the answer slide.
