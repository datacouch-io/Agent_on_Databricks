What is a human-in-the-loop approval gate?

A human-in-the-loop gate is code that inspects a tool call the model has requested and refuses to execute it without a person's approval.

The trigger

A condition on the tool name and its arguments. In the lab: issue_refund at or above £50, above the order total, or above it once earlier refunds are added up.

The check

An ordinary Python function. No model involved, no prompt, no ambiguity.

The outcome

The call does not run. A refusal is appended to state, and the model explains it to the user.

Where it sits

Between the model's decision and the function body — step 3 of the loop.

It is not a filter on the answer

You are not checking the text the agent produces. You are checking an action before it has an effect.

It is not the model's choice

The gate fires whether or not the model agrees it should. It cannot be reasoned with, because it is not reading prose.

The analogy

A card machine that requires a PIN above a threshold. The shopkeeper's good intentions are irrelevant to whether it asks.

15

Short definition slide, but define it precisely because the term gets used loosely. A human-in-the-loop gate is not content moderation and it is not a confirmation dialog bolted onto the UI. It is a check on a proposed action, in the one window where the action has been fully specified and not yet taken. Stress the second panel. The gate is not something the model opts into. People find this uncomfortable at first because it feels like distrusting your own system; it is the same instinct that puts a limit on a card rather than a note in the cardholder's wallet. On the threshold itself: fifty pounds is arbitrary and that is fine. What matters is that the number lives in code, in version control, with a test — not in a paragraph of a prompt that someone will later reword for tone. Likely question: "Does this not ruin the user experience?" The opposite, done well. The lab's agent still looks up the order and quotes the policy; it just tells the customer a human will authorise the payment. A graceful boundary reads as competence. A silent unauthorised refund reads as a breach. Timing: 3 minutes.
