What is Databricks AI Search?

Databricks AI Search is Databricks' managed vector index. A vector index stores numeric representations of text (embeddings) so you can retrieve passages by meaning rather than by keyword.

Delta Sync index

Points at a Delta table and stays current with it. You maintain no pipeline.

Managed embeddings

The platform embeds your text column with a model you name — databricks-gte-large-en.

A Unity Catalog object

Three-level name, its own grants, visible lineage back to the source table.

Endpoint

The compute that serves searches. One endpoint hosts many indexes.

Two requirements on the source table

A primary key so rows can be identified, and Change Data Feed enabled so the index can see what changed. Both are one-line table properties.

The analogy

A library catalogue that reindexes itself when a book is reshelved — rather than a photocopy of the catalogue that was accurate last Tuesday.

Define three terms here and do not skip any of them: embedding, vector index, and Delta Sync. Someone in the room has used RAG without ever creating an index themselves. The idea that reframes this for most people is in the first card. You do not load documents into a vector database. You point an index at a table and the platform keeps it current. Inserting a row into the Delta table is how you add a document; there is no second system to write to and no ingestion job to own. Change Data Feed is the mechanism and worth naming: it is the Delta feature that records row-level changes, which is how the index knows what to re-embed instead of rebuilding everything. Managed embeddings is the trade to flag now and argue in the next slide: you give up choosing the embedding model, and you never run an embedding job. Analogy: a self-updating library catalogue versus a photocopy of one. Likely question: "What about chunking?" That is your job, upstream, in the table. The index embeds the column you point it at, so the rows in that table are your chunks. Chunk badly and no amount of search quality rescues it. Timing: 3 minutes.
