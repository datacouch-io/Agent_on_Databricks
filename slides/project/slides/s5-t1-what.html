What is a Unity Catalog function as a tool?

A Unity Catalog function is a SQL or Python function registered as a catalog object. Registered that way, it is a tool definition: its signature, its comment and its grants become the schema, the description and the access control.

A catalog object

Three-level name — catalog.schema.function. Versioned, owned, auditable.

Typed signature

Becomes the JSON schema the model reads. Types are enforced by the engine.

COMMENT is the description

Both on the function and on each parameter. This is prompt text in DDL.

GRANT is the permission

GRANT EXECUTE decides who may call it. Enforced by the platform.

Definer's rights

The function body runs as its owner. A caller needs EXECUTE on the function, and does not need SELECT on the table inside it.

The analogy

A bank teller window. You can ask for your balance; you cannot walk into the vault. The teller has the access, and only answers the question you are allowed to ask.

Define DDL if anyone looks unsure — Data Definition Language, the CREATE and GRANT statements. The idea on this slide is that your tool definition is written in it. The four cards are the same object seen four ways, and the mapping is the content: signature becomes schema, comment becomes description, grant becomes access control. Nothing is generated or synced; the catalog object is the single source of all three. Definer's rights deserves its own moment because it is the feature that makes least privilege practical here. The function body executes as the owner, so you grant EXECUTE on a function that looks up one order by id, and you never grant SELECT on the orders table. The agent can answer a question about an order and cannot read the order book. That is a much better boundary than any filtering you could do in application code. The bank teller analogy carries it: you may ask for your balance, you may not enter the vault, and the teller only answers the question you are entitled to ask. Likely question: "Can tools be Python, not SQL?" Yes — Python functions register in Unity Catalog too, with the same comment and grant semantics. Start with SQL for anything that is fundamentally a query. Timing: 4 minutes.
