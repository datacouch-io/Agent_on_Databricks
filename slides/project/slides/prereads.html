What You Are Expected to Know

The pre-read video covers everything below. It is required if you are not already comfortable with Python or SQL, and useful background for everyone else.

Python

Basic syntax, functions, dictionaries and lists, and reading a traceback. You will edit notebooks, not write libraries.

SQL

SELECT, JOIN, GROUP BY, filtering. Enough to read a generated query and say whether it is right.

Spark, PySpark, Spark SQL

Distributed computing basics and the DataFrame idea. Background only — no Spark is written in the labs.

The Databricks interface

Workspace, notebooks, Catalog Explorer, attaching serverless compute. A short walkthrough is in the video.

LLM and agent basics

Prompting, embeddings, RAG, and roughly what an agent is. Session 1 re-establishes the definitions anyway.

Lakehouse and Delta Lake

Optional background. Helpful for Session 3, not required.

Not assumed — these are taught here

MLflow and tracing · Databricks AI Search · Unity Catalog functions and grants · MCP · Genie, its Knowledge Store and the ontology · Model Serving · agent evaluation.

This slide exists because people arrive unsure whether they are the right audience, and that uncertainty costs you the first twenty minutes. Read the top line out: the video is required only if Python or SQL are not already comfortable. For a cohort that has done the Claude or CCAF training, most people will skip it. Go down the six rows quickly, but land the qualifiers, because they lower the barrier honestly. Python: you edit notebooks, you do not write libraries. SQL: enough to read a generated query and judge it — which is exactly the skill Session 4 needs when Genie writes SQL for you. Spark: background only; no Spark is written in any lab, and saying so stops a Spark-shaped worry. The dark panel is the one that settles the room. Everything genuinely new is taught here: MLflow, AI Search, Unity Catalog functions, MCP, Genie, Model Serving, evaluation. Nobody needs to revise those in advance, and anyone who already knows them will still get the governance argument. Close on the bottom bar. A working workspace on the day is worth more than having watched every minute of the video — and the pre-flight check on the next slide is how they get one. Expected question: "I have never used Databricks at all." You will be fine. The interface walkthrough in the video plus the pre-flight check is enough; the labs give exact click paths.
