What is an evaluation dataset?

An evaluation dataset is a fixed set of inputs — and, where you have them, expected outputs or expectations — that you run the agent against so that two versions can be compared on the same ground.

Inputs

Realistic requests, including the awkward ones. Phrased as users phrase them.

Expectations

What a good answer must contain or must not do. Not necessarily an exact string.

Fixed

The same set every run. A dataset that changes between runs measures nothing.

Versioned

An MLflow dataset object, so a result can be tied to the data that produced it.

Why not just exact-match answers?

Agents produce prose. Two correct answers can share no sentences. Expectations capture what must be true — cites a policy, declines politely, states the order date — rather than the wording.

The analogy

A driving test route. Fixed, deliberately awkward in places, and the same for every candidate — which is the only reason the pass is meaningful.

Start with what makes a dataset a dataset: it is fixed. That sounds trivial and it is the part teams get wrong, because the natural workflow is to try whatever question is on your mind. Doing that, you cannot tell improvement from a different question. The second card and the white panel are the real content. Agents emit prose, so exact matching is hopeless — two correct refunds answers may share no phrases. What you can state is what must be true: it cites a policy document, it mentions the order date, it does not promise a refund it cannot authorise. Those are checkable without pinning wording. Call out the awkward cases explicitly. A dataset of easy questions tells you nothing, because everything passes. The valuable rows are the ambiguous question, the out-of-scope question, the one where the right answer is "I cannot help with that", and the one where policy says no. Analogy: a driving test route — fixed, deliberately awkward, identical for everyone. Likely question: "How big should it be?" Twenty to fifty well-chosen rows beats five hundred scraped ones. Each row should be there because it tests something distinct, and you should be able to say what. Timing: 3 minutes.
