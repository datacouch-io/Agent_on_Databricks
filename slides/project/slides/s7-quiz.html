Session 7 — Operations, Multi-Agent Systems and Best Practices

Knowledge check

Four questions. One correct answer each — answers on the next slide.

1

Your retriever filtered on audience='customer' and never returned DOC-006. A Knowledge Assistant on the same index disclosed it. Why?

A  The assistant used a different embedding model

B  DOC-006 was re-indexed without its audience column

C  The filter was an argument your code passed, not a property of the index

D  The assistant was granted broader permissions on the index

2

When is splitting one agent into a supervisor and workers justified?

A  When you can name the reason: tool count, differing identities, separate owners, or different models

B  When the prompt has grown beyond a page

C  As soon as the agent has more than one tool

D  Whenever latency needs to improve

3

A canary shows the challenger refusing 1 of 3 probes. The champion refused 2 of 3 over the same window. What is the honest conclusion?

A  Revert — any refusal increase is a regression

B  Promote — the challenger refused less

C  Split traffic 50/50 to gather data faster

D  No decision — n = 3 supports neither conclusion; widen the probe set

4

How do you state an agent's total data freshness?

A  The longest single lag in the chain

B  The sum of source lag, index lag, semantic lag and cache lag

C  The index sync interval, since retrieval dominates

D  The cache TTL, since it is applied last
