What is token optimization?

Reducing the tokens an agent spends per resolved request — without reducing the quality of the answer. The denominator matters: cheaper per call is not cheaper per outcome.

Input tokens

Re-paid on every turn. The system prompt, the conversation, retrieved context, tool schemas.

Output tokens

Usually smaller and more expensive per token. Verbose answers cost twice — money and reading time.

Step count

The multiplier. Every extra loop re-pays the whole input.

Prompt caching

Where supported, a stable prefix is charged at a reduced rate. Order your prompt to exploit it.

The metric that matters

Tokens per resolved request, not tokens per call. An agent that is cheap per call and needs five turns is more expensive than one that costs more and finishes in two.

The analogy

Fuel economy, not the price of a litre. The number you care about is per journey completed.
