What keeps a Delta Sync index current with its source table?

A  A scheduled notebook that re-embeds the table

B  A trigger on the table that calls the index API

C  The primary key plus Change Data Feed, which tells the index what moved

D  Nothing — you must rebuild the index after each change

Why does chunking set the ceiling on everything downstream?

A  Because embedding models have a fixed token limit

B  Because the index charges per chunk stored

C  Because chunk size determines the embedding dimension

D  Because search ranks only what you gave it — if the answer is not a retrievable unit, nothing recovers it

3

Your query over the trace-spans table fails with UNRESOLVED_COLUMN. What is the most likely cause?

A  You wrote status_code; these are OpenTelemetry spans, so it is status.code

B  The traces have not finished writing yet

C  The destination was never set to a Unity Catalog schema

D  Span types must be registered before they can be queried

4

You must classify 4,000 support emails per night into a fixed set of categories. What should you build?

A  An agent with a classification tool and MAX_STEPS of 2

B  An AI Function — ai_classify — called from SQL

C  A multi-agent system with one worker per category

D  A Genie Agent over the email table
