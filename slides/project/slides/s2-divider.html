Platform-Agnostic Agent Implementation

Goal: write the agent once, then change the retriever underneath it without touching it.

2 hours  |  Labs 2A, 2B

Session 2 is the architecture session disguised as a plumbing session. Every framework in this space will tell you it is the right abstraction. The useful question is narrower: which parts of my agent must know which vendor I chose? In the lab the answer is exactly one function, and we prove it by swapping what sits behind it. Timing: 1 minute.
