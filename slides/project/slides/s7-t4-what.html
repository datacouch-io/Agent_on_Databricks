What is data freshness for an agent?

The lag between a fact changing in your business and the agent answering as though it had. Every grounded agent has one, and most teams have never measured it.

Source lag

How often the source table is updated from the system of record.

Index lag

TRIGGERED sync interval, or CONTINUOUS. Only applies to retrieval.

Semantic lag

How long before a changed definition reaches metric views and the ontology.

Cache lag

Anything you cached — responses, embeddings, context — to save money.

Total

The sum, not the largest. This is the number to quote to the business.

The failure has no error

A stale index does not break. Searches succeed, scores stay high, and the agent cites a policy you withdrew last month — confidently, with a real document id.

The analogy

A printed price list. Nothing about it looks wrong; it is simply from before the price changed.
