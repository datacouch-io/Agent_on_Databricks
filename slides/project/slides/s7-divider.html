Operations, Multi-Agent Systems, Agent Bricks and Best Practices

Goal: split an agent, canary a change, and watch a managed assistant inherit nothing.

2 hours  |  Labs 7A, 7B

The last session is the operational one, and it contains the course's sharpest demonstration. Three things: splitting one agent into a supervisor and workers, deploying a change to a fraction of traffic, and handing the same AI Search index from Session 3 to a managed Knowledge Assistant — which discloses an internal document, because the filter that protected it was ours and not the index's. Timing: 1 minute.
