# the adapter — the only environment-aware code
def build_runtime():
    w = WorkspaceClient()  # resolves per runtime
    return Runtime(
        client=OpenAI(base_url=f"{w.config.host}/serving-endpoints",
                    api_key=w.config.token),
        retriever=make_retriever(CFG.index),
        cfg=CFG,
    )

agent = Agent(**build_runtime().as_kwargs())

What the agent never sees

No host, no token, no index name, no vendor import. It receives a client, a retriever and a config object.

That is the whole of portability: one function knows where it is, and it is not the agent.

Config as one object, not scattered constants

Model name, MAX_STEPS, top-k, thresholds. One dataclass you can print into a trace, diff between runs, and attach to an evaluation result.

Why that matters in Session 6

A config you can print is a config you can attribute a score to. Scattered constants cannot be compared.

Eleven lines, and the point is the shape rather than the detail. One function is environment-aware. It asks the SDK for whatever identity this runtime has — a local profile, the notebook user, a job's service principal, an endpoint's own identity — and hands back a fully-constructed client, a retriever and a config object. The agent is assembled from those and knows none of it. Point out that WorkspaceClient is doing the heavy lifting: it resolves credentials differently in each of the four runtimes, which is exactly the variation you do not want spread through your code. The config-as-one-object point is worth more than it looks and it pays off twice. In Session 6 you need to attribute an evaluation score to a configuration — model, max steps, top-k, thresholds. If those are scattered constants across three modules, you cannot record what produced a result, so you cannot reproduce it. A single config object prints into a trace and attaches to a run. Likely question: "Where do defaults live?" In the config object, with environment overrides. Not as function keyword defaults scattered through the agent, where they are invisible to a reader and unloggable. Timing: 4 minutes.
