What is context engineering?

Context engineering is deciding what goes into the model's context window on each turn — and what stays out. The window is a budget, not a bucket.

System prompt

Role, rules, tone. Constant across turns, so it is paid for on every one.

Conversation

The growing messages list, including every tool result you appended.

Retrieved context

Documents and rows fetched this turn. The largest and most variable part.

Tool schemas

Every tool's name, description and parameters, sent on every request.

The four levers

Select what to include · compress what is long · order so the important sits near the instruction · evict what the next step cannot use.

The analogy

A briefing note for a colleague about to walk into a meeting. Everything relevant, nothing else, and the decision they must make at the top.

This topic is in the outline and it is the one most teams discover by accident, usually when a bill or a latency graph forces it. Define it precisely: context engineering is the set of decisions about what occupies the context window on each turn. Not prompt wording — occupancy. Four things compete for that space and the slide names all four, including the two people forget: tool schemas are re-sent on every single request, and the conversation grows monotonically because every tool result is appended to it. The four levers are the actionable part. Select: do you need all five retrieved documents, or the two above a score threshold? Compress: does the tool return a summary or a result set? Order: models attend most reliably to the beginning and end, so the question belongs near the instruction, not buried in the middle of ten documents. Evict: once a sub-task is finished, its intermediate tool output is dead weight. Analogy: a briefing note for someone walking into a meeting. The skill is leaving things out. Likely question: "Models have huge context windows now — does this still matter?" More than before. A large window means you can fit everything, pay for everything, wait for everything, and dilute the model's attention across it. Capacity removed the hard limit, not the trade-off. Timing: 4 minutes.
