Session 5 — Tools and Governance

Knowledge check

Four questions. One correct answer each — answers on the next slide.

1

Register a SQL function in Unity Catalog as a tool. What does its COMMENT become?

A  The tool description the model reads when deciding whether to call it

B  Documentation shown only in Catalog Explorer

C  A validation rule applied to the arguments

D  The commit message in the function's version history

2

The same MCP endpoint, the same request, two tokens. The restricted principal lacks EXECUTE on issue_refund. What does its tools/list return?

A  All three tools, with issue_refund marked unavailable

B  All three tools; the refusal happens at call time

C  Two tools — issue_refund simply does not appear

D  An authorization error for the whole request

3

A Unity Catalog function runs with definer's rights. What should you grant the agent's principal?

A  SELECT on the underlying table

B  EXECUTE on the function, and not SELECT on the table

C  Both EXECUTE and SELECT, so the agent can fall back to raw SQL

D  Ownership of the schema containing the function

4

A tool call fails with a network timeout. What should the tool return to the loop?

A  Raise the exception and let the loop crash — failures should be loud

B  Return an empty result so the model moves on

C  Retry indefinitely until it succeeds

D  A tool message describing the failure, classified as transient so a retry is justified

121

Answer key: 1A, 2C, 3B, 4D. Run this as a poll, not a lecture. Read each stem aloud, take a show of hands on every option, and only then move to the answer slide. The wrong answers are not filler — each one is a misconception this session exists to correct, so a room that splits is more useful to you than a room that is unanimous. If most of the room picks the same wrong option, stop and re-teach that point before moving on. That is the signal this slide is for. Timing: 5 minutes for the four questions, plus 4 minutes on the answer slide.
