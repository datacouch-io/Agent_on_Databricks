That is the entire agent. Everything else in this course is making one of those boxes governed, measured or safe. Walk the loop aloud once: ask the model; if it returned text and no tool calls, we are done; otherwise run each tool it picked, append the result to the conversation, and go round again. On stopping conditions: the model decides what to do next — you keep the decision about how long it may keep going. That separation is the point. If you routinely hit five of six steps, your tools are too granular. Lab exercise: set MAX_STEPS to 1 and re-run the happy path. A working agent now fails, and the sentinel tells you why. Expected question: "Why append tool results as messages rather than keeping state separately?" Because the model needs them in context to decide the next step.
