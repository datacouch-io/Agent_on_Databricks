What are Foundation Models?

Foundation Models are pay-per-token model endpoints hosted in your Databricks workspace, reachable through an OpenAI-compatible interface — the same request format the OpenAI client library uses.

Pay-per-token

No cluster to size, no endpoint to keep warm. You are billed for tokens used.

One base URL

Your workspace host plus /serving-endpoints. Authentication is your workspace token.

Model by name

databricks-claude-sonnet-5, and others. Changing model is changing a string.

Same client

The openai Python package, pointed at Databricks. Your agent code does not change.

Provisioned throughput is the other mode

For steady, high-volume workloads you reserve capacity instead of paying per token. Same interface, different billing and latency profile.

The analogy

A standard plug socket. The generating station changed; your kettle did not notice.
