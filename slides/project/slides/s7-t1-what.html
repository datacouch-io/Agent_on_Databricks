What is a multi-agent system?

A multi-agent system splits work across several agents, each with its own instructions and its own tools. The common shape is a supervisor that routes to workers and composes their answers.

Supervisor

Decides which worker handles a request. Has no domain tools of its own.

Workers

Narrow agents — an orders specialist, a policy specialist. Each with few tools.

Routing

A decision like any other: the supervisor's model chooses, at runtime.

Context

Each worker sees only what the supervisor passes. This is the design's sharpest edge.

The variants worth knowing

Supervisor-worker for routing. Sequential for pipelines where each stage refines the last. Parallel with a reducer where independent lookups are combined.

The analogy

A switchboard with specialists behind it. Faster when the specialists are genuinely different, and worse than one good generalist when they are not.

Define it, and immediately set the expectation that this is a pattern with real costs — the next slide is about when not to use it. The supervisor-worker shape is the one to teach because it generalises. A supervisor whose only tools are the workers themselves, and workers that are ordinary agents from Session 1 with narrow tool sets. Nothing new is required; it is agents all the way down. The fourth card is the one to flag now and demonstrate in Lab 7A. Each worker sees only what the supervisor chose to pass. That is the feature — narrow context, focused behaviour — and the failure mode, because a worker denied a relevant fact does not know it is missing and answers confidently anyway. Name the other two variants briefly so people recognise them in the wild: sequential pipelines where each stage refines the previous output, and parallel fan-out with a reducer for independent lookups. Analogy: a switchboard with specialists. Good when the specialists are genuinely different; worse than one competent generalist when they are not. Likely question: "Is this not just function calling with extra steps?" Often, yes — and that is the honest answer.
