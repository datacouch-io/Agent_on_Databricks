Why a rule at the data travels, and a rule in the caller does not

Session 3 — the filter in the caller

Our retriever passed filters={'audience': 'customer'}. Correct, tested, and effective for every call we made. It protected nothing else.

Session 4 — the rule in the space

“Revenue excludes cancelled orders” lives where the query executes. Every caller gets it, including callers that have never heard of it.

Why the difference matters

A control's reach is decided by its location, not by its correctness. Both of ours were correct. One was inherited and one was not, and you cannot tell which from reading the code that uses it.

The test to apply

Ask: if someone else wrote a new client for this data tomorrow, would this rule still apply? If the answer is no, it is a convention, not a control.
