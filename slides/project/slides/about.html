About this course

Who it is for

Data and ML engineers, developers. Intermediate to advanced.

Assumed

Python, SQL, and LLM basics — prompting, embeddings, RAG.

Format

7 × 2h live, with fifteen hands-on labs.

By the end you will be able to

  • Build an agent with tools, state and a stopping condition
  • Ground it in governed enterprise data
  • Govern its tools with Unity Catalog grants
  • Evaluate it, and distrust the evaluation
  • Deploy it to Model Serving and query it
  • Operate it — canaries, rollback, multi-agent flows

3

Those six verbs map one-to-one onto what the fifteen labs build. Nothing is asked of you that we do not practise together first. The fourth one is the odd-looking item: "evaluate it, and distrust the evaluation". That is not a joke. While building this course, three separate automated judges turned out to be wrong — penalising correct refusals, failing correct answers against rules the question never invoked. Reading a metric without reading its reasoning is the most common expensive mistake in this field. A prerequisite video covering Python, SQL and a Databricks interface walkthrough is on the LMS. It is required only if you are not already comfortable with Python or SQL basics. Expected question: "How much of this is Databricks-specific?" Four of the fourteen hours are deliberately platform-agnostic — Sessions 1 and 2 — before Databricks is mentioned at all. Timing: 3 minutes.
